# MRS Monitor Processual

![MRS Monitor Processual](MRS_Monitor_Processual_GitHub_1280x640.png)

Aplicativo Windows da **MRS Sistemas** para acompanhamento online de processos judiciais pelo número CNJ.

## Principais recursos

- Cadastro de processos pelo número CNJ.
- Consultas online programadas em horários definidos pelo usuário.
- Avisos internos quando forem encontradas novas movimentações.
- Histórico completo das consultas e movimentações.
- Identificação de datas relevantes para apoio ao agendamento.
- Teste gratuito por 15 dias.
- Estrutura preparada para receber módulos adicionais no futuro.

## Requisitos

- Windows 10 ou Windows 11, 64 bits.
- Conexão com a internet para realizar as consultas processuais.
- Espaço livre para instalação e armazenamento do histórico.

Esta edição utiliza banco de dados SQLite local e **não necessita do Firebird**.

## Instalação

1. Baixe **Instalador.exe** pelo link acima.
2. Execute o instalador no Windows.
3. Siga as etapas exibidas na tela.
4. Consulte o manual PDF disponibilizado junto do instalador.

## Observações importantes

As consultas dependem da disponibilidade e das regras dos serviços públicos dos tribunais. Processos sigilosos, consultas protegidas por CAPTCHA ou dados não disponibilizados publicamente podem exigir conferência manual no portal oficial.

O sistema é uma ferramenta de apoio. Prazos, audiências e movimentações devem ser confirmados pelo profissional responsável nos canais oficiais do Poder Judiciário.
